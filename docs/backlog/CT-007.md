# CT-007 Perfetto flows and protobuf export

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Add flows (work item ↔ topic, span ↔ build) and counter tracks (WIP count, CI queue
depth) to the trace, and an optional `.pftrace` writer behind a `cycle-time-perfetto`
extra with a pinned `perfetto` version. The JSON writer stays the default.

## Acceptance evidence

Flows connect the expected slices in a scenario trace; the protobuf writer is skipped
cleanly when the extra is missing.
