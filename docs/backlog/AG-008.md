# AG-008 Harden WIQL quoting and keyset pagination

The project builder uses backslash quoting while the filter builder doubles
quotes; skipped-type names are interpolated unescaped; the ORDER regex can match
string literals.

## Acceptance evidence

Apostrophes and ORDER inside names, paging over 20k IDs and non-advancing pages
are covered with SDK fakes and an optional real-server contract test.
