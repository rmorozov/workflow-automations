# AG-003 Completion status instead of treating omitted IDs as a complete graph

Omitted IDs are counted and logged; still missing is a completion status or exit
code instead of treating `error_policy=Omit` as a complete graph. Use triage's
core-vs-label failure distinction.

## Acceptance evidence

Missing seed or bridge IDs yield an explicit incomplete/failure status and
reproducible counts.
