# AG-012 Versioned snapshot schema and provenance manifest

Define a versioned snapshot schema and provenance manifest (query, collection,
fields, filters, relation policy, timestamps, tool version, completeness); add
replay and CSV/XLSX ingestion if needed. The schema is a contract that both ADO
tools will read, so design it with SH-004 and TR-009.

## Acceptance evidence

Old and new snapshots validate; identical snapshots feed both the graph and the
triage pipelines offline.
