# AG-010 Offline analysis without Azure SDK or Kerberos

Make local analysis installable without Azure SDK/Kerberos; move imports and
client configuration to the network boundary (`client.py`, imported lazily by
the export command). Remove import-time global logging and temporary CA or
environment side effects; clean up and restore prior CA settings. Split the
`ado-graph` extra into an offline analysis extra and a network extra.

## Acceptance evidence

Offline `analyze` and `--help` work with no network extras installed; importing
the library does not configure root logging; CA cleanup works on failure.
