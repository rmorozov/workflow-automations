# CT-005 Normalize and link

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Turn landing rows into the input file: work item ↔ topic links from `TFS: #id`
footers and `wi-<id>` topic names (with `link_source` and confidence), topic
identity (topic string plus time contiguity, so a reused string is two topics), the
comment ↔ build join (`build-run-id` footer, else fuzzy time match), and people
replaced by salted pseudonyms before anything is stored.

## Acceptance evidence

Fixtures cover a multi-ID footer, a renamed topic, a reused topic string and a CI
comment without the footer; no name or account appears in the normalized output.
