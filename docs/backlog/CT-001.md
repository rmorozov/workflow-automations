# CT-001 Fetch ADO work item state history

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

The shared ADO code fetches current fields only. Add a read-only fetcher for work item
updates (revisions) that returns each `System.State` change with its revision number
and `System.ChangedDate`, in batches, through `ado_common.session`. It lives in
`ado_common` because ado-triage can use state history too.

## Acceptance evidence

A fake SDK client with three revisions, two of them in the same second, gives state
entries in revision order; a missing work item is reported, not raised.
