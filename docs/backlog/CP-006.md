# CP-006 ado-triage splits remaining work by Activity

Design: [Team capacity model design](https://claude.ai/code/artifact/ff3e10f9-39d4-4a50-935e-c54f795d2ea5).

Remaining work is one number per item, so testers' capacity cannot be compared
with testing work. Read `Microsoft.VSTS.Common.Activity` on child tasks, map
activities to role groups (Development to developer, Testing to test, and so on,
configurable), and compare each group's remaining work with its capacity. Items
without tasks or activities keep today's single pool.

## Acceptance evidence

A synthetic snapshot with development and testing tasks under one CR shows a test
overload that the single-pool view hides; snapshots without Activity give today's
results.
