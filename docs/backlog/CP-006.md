# CP-006 Work type on change requests for role-aware triage

Design: [Team capacity model design](https://claude.ai/code/artifact/ff3e10f9-39d4-4a50-935e-c54f795d2ea5).

Ruslan decided (2026-10-20) that `ado-triage` compares remaining work only with the
capacity of developers and team leads, because a CR's remaining work is development
work. Later, CRs get a work type (development, testing, architecting) so other role
groups' capacity can be matched to their own work. Agree on how the work type is
recorded in ADO first (a CR field or a split of remaining work), then compare each
work type's remaining work with its role group's capacity. CRs without a work type
count as development, which keeps today's results.

## Acceptance evidence

A synthetic snapshot with development and testing work under one team shows a test
overload that the development-only view hides; snapshots without work types give
today's results.
