# AG-018 Split ado_graph.py into a package along its existing seams

`ado_graph.py` is one 1,458-line module, so almost every AG task edits the same
file and two parallel branches on it conflict. Move code, without behavior
changes, into a package: `cli.py` (parser, `main`), `client.py` (ADOClient, auth,
CA, WIQL builders), `export.py` (traversal, `run_export`, ExportStats),
`analyze.py` (GraphAnalyzer, contraction), `report.py` (Excel/CSV/Parquet
writers and sizing). `__init__.py` re-exports `main`, so the entry point,
`python -m workflow_automations.ado_graph` and the script wrapper keep working.
Split `tests/ado_graph/test_ado_graph.py` by the same modules.

Pure move: no renames, no fixes. Reviewers diff the moved bodies, not the logic.
Run it alone, before any other AG task starts, and merge it quickly.

## Acceptance evidence

All existing tests pass unchanged apart from import paths; CI smoke tests for
`ado-graph --help`, `ado-graph analyze --help` and `python -m` still pass; `git
diff --stat -M` shows moves, not rewrites.
