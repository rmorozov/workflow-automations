# CT-004 ADO pipeline runs and build-log adapters

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Read validation build runs (queued, started, finished, result, topic) from ADO Pipelines,
and walk the share for each run's directory, keeping per-tool start and finish lines
with their time-zone source (`explicit` or `inferred`). Log times refine pipeline
times; missing logs fall back to the pipeline with `ts_source = ado_pipeline`.

## Acceptance evidence

Synthetic run records and log directories give builds with the expected times; a log
without a zone is flagged `inferred`; a missing directory falls back.
