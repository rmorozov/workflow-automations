# CT-003 Gerrit REST adapter

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Read topics, changes, patchsets (with WIP at upload), change messages (WIP and
Ready-for-review toggles, votes, CI comments) for a time window, read-only, into the
landing store. Handle the `)]}'` JSON prefix and paging. Record the Gerrit version,
because message wording differs between versions.

## Acceptance evidence

Recorded synthetic responses produce the landing rows; a WIP toggle and a vote parse
into change events with UTC times.
