# AG-016 Excel limits preflight, spill to Parquet/CSV, bounded column sizing

Preflight Excel's row/column/cell limits before publication; CR×reachable and
cycle-member sheets can exceed 1,048,575 data rows plus header. Spill large detail
sheets to Parquet/CSV with pointers in the workbook, or fail before any output is
replaced. Replace the full openpyxl cell walk for widths with bounded sampling;
vectorized full-column sizing remains O(cells). Remove the bare except and report
sizing failures explicitly. Found in the PR #11 review.

## Acceptance evidence

Boundary tests for supported counts and spill behavior; existing outputs survive
overflow; large-report benchmarks separate graph compute, writing and sizing time.
