# TR-011 Items without an AreaPath, and per-team output docs

A work item with no `System.AreaPath` has NaN AreaPath and `Matched_Capacity_Level`. Two
results follow. If its `RemainingWork` is above 0, `view_top_20_percent` crashes with
`IntCastingNaNError`, because `groupby` drops the NaN group. Separately, groupby
silently leaves the item out of `1. Executive Summary` and `4. Capacity Triage`.
Treat a blank AreaPath as one explicit team, the same one the `--team-dir` file
`NO_AREA` uses, in every view.

Also document `--team-dir` (TR-001) in the README triage section and in the spec's
verification list.

## Acceptance evidence

A snapshot with an item that has no AreaPath and has remaining work produces a
report. The item appears in the Top 20%, Executive Summary and Capacity Triage
sheets. The README and the verification list mention per-team output.
