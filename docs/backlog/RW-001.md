# RW-001 Branch protection with the shared CI checks required

Enable branch protection or rulesets and require the `quality` and `test` checks. This is an owner setting on GitHub, not a code change; the task is done when the owner turns it on.

## Acceptance evidence

A PR with a failing required check cannot be merged.
