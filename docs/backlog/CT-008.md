# CT-008 Discovery probe for one team and month

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

builds per topic, Resolved minus Ready-for-review delays, cross-system skew and the
