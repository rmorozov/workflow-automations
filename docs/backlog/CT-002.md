# CT-002 Append-only landing store

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Keep verbatim payloads (ADO updates, Gerrit change details and messages, pipeline runs,
log excerpts with file hashes) in an append-only SQLite store keyed by source, object
ID and fetch time, following the `ado_common.snapshot` conventions (versioned schema,
refuse overwrite, atomic writes). Normalizing reads only from here.

## Acceptance evidence

Storing the same payload twice keeps one row; a changed payload adds a row; the
normalizer's output for a fixture store is byte-identical across two runs.
