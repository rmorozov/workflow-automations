# CP-003 team-capacity CLI and output workbook

Design: [Team capacity model design](https://claude.ai/code/artifact/ff3e10f9-39d4-4a50-935e-c54f795d2ea5).

Add the `team-capacity` entry point (`--roster`, `--config`, `--start-month`,
`--months`, `--output`, `--overwrite`, `--allow-problems`) and write one workbook
atomically: `dev_per_area_capacity` in exactly the contract `ado-triage
--capacity-file` reads today (AreaPath, then `YYYY-MM` columns of net
change-request hours of the triage-pool groups), `capacity_by_role` (AreaPath,
group, period type and period, people, FTE, gross, ritual, illness, bug-fix, focus,
net hours), `capacity_by_person` and `problems`. Problems make the run exit
non-zero unless `--allow-problems`.

## Acceptance evidence

`ado-triage`'s own `load_capacity` reads the generated `dev_per_area_capacity`
for the window and returns the expected totals; per-role sums equal per-person
sums; an existing output needs `--overwrite`; the entry point is smoke-tested in CI.
