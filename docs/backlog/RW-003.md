# RW-003 Provider-neutral task tiers and Codex agent profiles

Task files name a Claude model (`model: opus`), which is not meaningful to other
providers. Replace it with a provider-neutral tier (routine implementation,
complex semantics, deep review) and map each tier to models per provider in
`docs/agentic-workflow.md`. Add Codex role files under `.codex/agents/` as a
separate adapter next to `.claude/agents/`, sharing the task schema, acceptance
evidence, ownership rules and check commands. Proposed in the PR #13 review.

This touches every task file, so run it alone, when no other branch edits
`docs/backlog/`.

## Acceptance evidence

`backlog.py check` validates the neutral tier; every task file uses it; each
Codex profile is shown, by a small probe in the real client, to load its intended
model, effort and sandbox; one ordinary task and one graph-semantics task are
piloted with it.
