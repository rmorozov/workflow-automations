# AG-021 Cycles sheet shows the links that close each cycle

The node sheets carry `Graph_Neighbors_Debug`, but the cycles sheet lists only
member IDs, so finding which links form a cycle means looking each one up in ADO.
Add `Cycle_Edges_Debug` to every cycle member row: the link from the previous
member and the link to the next, with link types as the step's subgraph has them.

## Acceptance evidence

A synthetic three-item cycle with a parallel hierarchy link shows each member's
incoming and outgoing cycle link; on `cycles@dependency` only the dependency
type is named; the empty sheet still has the column.
