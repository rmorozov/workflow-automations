# AG-002 Atomic publication and explicit overwrite for export and analyze

both modes; multi-file export needs a staged bundle. Reuse the tested publication
approach of `ado-triage` (`publish`) rather than inventing a new one; promoting

input; overwriting requires consent via a flag.
