# AG-004 Explicit graph semantics for relation types, parallel links and subgraphs

Keep relation types separate; preserve parallel links; choose hierarchy,
dependency and impact subgraphs explicitly. Reverse CR reachability currently
means ancestors despite the "CR dependency" name. Coordinate relation parsing
with SH-003.

## Acceptance evidence

Synthetic CR→child, predecessor→CR and multiple-type edges have documented,
distinct outputs; no labels are silently overwritten.
