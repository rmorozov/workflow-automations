# AG-020 Long text cells over Excel's 32,767-character limit

Excel stores at most 32,767 characters in a cell. Today one long ADO text field makes
`export`/`replay` refuse the whole `work_items.xlsx`, and makes `analyze` move the whole
sheet to a CSV spill file. Make the handling configurable (flag and options file):
trim the cell in its sheet with a marker that links to the full text, and write the
full text to a separate sheet split across cells; or only trim; or keep today's
behavior.

## Acceptance evidence

- Tests show a cell over the limit trimmed with a marker and linked, the full text
  reassembled exactly from the overflow sheet's parts, and each mode in export,
  replay and analyze, from the command line and from an options file.
