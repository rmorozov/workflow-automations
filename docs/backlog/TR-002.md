# TR-002 Write triage decisions back to ADO

Write triage decisions back to ADO as tags or comments; the tool stays read-only until then. Writing to ADO changes shared state outside the repository, so the design (dry run, opt-in flag, idempotency) needs the owner's approval before code.

## Acceptance evidence

A dry run lists every intended change; a real run is idempotent and opt-in.
