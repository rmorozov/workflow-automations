# CP-005 ado-triage shows capacity per role group

Design: [Team capacity model design](https://claude.ai/code/artifact/ff3e10f9-39d4-4a50-935e-c54f795d2ea5).

When the capacity file has `capacity_by_role`, show net hours per role group and
bug-fix hours beside remaining work in the summary and Capacity Triage.
`--capacity-groups` chooses which groups form the pool that load and RAG use
(default: the groups flagged as triage pool). Files with only
`dev_per_area_capacity` behave exactly as today.

## Acceptance evidence

A synthetic capacity file with developer, test and architect groups shows each
group's hours per team; changing `--capacity-groups` changes Load_Pct and RAG as
expected; an old capacity file gives byte-identical sheets to the current output.
