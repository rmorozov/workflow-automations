# CT-009 Options files for ingest commands

Design: [cycle-time specification](../specs/cycle-time.md) and the review in the project
files (`analysis/cycle-time-design-review.md`).

Move the CLI to `ado_common.options` (ConfigArgParse options files and
`--write-options`) once ingest needs server URLs, projects, teams and the share path,
and add the `cycle-time-ingest` extra.

## Acceptance evidence

An options file and the same flags give identical runs; the offline commands still
install and run without the ADO SDK.
