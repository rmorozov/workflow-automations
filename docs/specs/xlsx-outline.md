# XLSX outline specification, v1

Status: implemented initial contract. Entry points: `xlsx-outline`,
`python scripts/xlsx_outline.py`, or `python -m workflow_automations.xlsx_outline`.

## Goal

Hierarchical spreadsheets repeat parent values on every row: area, team and project
are copied left to right onto each task. A Markdown outline states each parent once
and nests what changes beneath it. The tool reads one sheet and writes that outline.
It is offline and deterministic; it uses openpyxl only (no pandas).

Example input:

| Area | Team | Item | Owner |
| --- | --- | --- | --- |
| Platform | Core | Scheduler | Ann |
| Platform | Core | Memory | Bob |
| Platform | Net | Routing | |
| Apps | Mobile | Login | Eve |

`xlsx-outline --input plan.xlsx --levels 3` writes:

```markdown
- Platform
  - Core
    - Scheduler
      - Owner: Ann
    - Memory
      - Owner: Bob
  - Net
    - Routing
- Apps
  - Mobile
    - Login
      - Owner: Eve
```

## Input

The input is an `.xlsx` workbook; it is opened for reading and never modified.
`--sheet` names the sheet; the default is the first sheet. The table begins at A1,
row 1 holds headings, and the table ends at the last nonblank cell. Every selected
column needs a nonempty heading; selected headings must be unique.

`--columns` selects headings by name and `--column-indices` by 1-based position; they
are mutually exclusive and default to all columns. Selection order is outline order,
so selection can also reorder the hierarchy (for example `--columns Owner Item`).

The first `--levels` selected columns (default: all) form the hierarchy. The
remaining selected columns are details: each row with a nonblank detail adds one
item `Heading: value; Heading: value` beneath its deepest hierarchy item, omitting
blank fields. Rows whose selected cells are all blank are skipped.

### Cell values

- Text is used as is, trimmed; line breaks inside a cell become one space, because
  a line break would end a heading or list item. Values are compared after this.
- Whole numbers render without a decimal part (`3.0` becomes `3`); booleans as
  `TRUE`/`FALSE`; dates at midnight as `YYYY-MM-DD`, other date-times in ISO format.
- Formulas render the value Excel cached when the file was last saved. The tool
  does not calculate formulas, so a workbook never saved by Excel (for example one
  generated by a script) shows formula cells as blank.
- A merged range displays its top-left value in every cell it covers, matching how
  the sheet looks in Excel.

## Folding rule

Rows are processed in sheet order. A row joins the previous row's item at each level
while all values to its left, and the value itself, equal the previous row's. At the
first difference, a new item starts and every level to its right starts anew. A
level the previous row did not reach (its path ended earlier) is a difference, so
`A | X`, `A | (empty)`, `A | X` yields two `X` items under one `A`. This is the
left-to-right duplication the outline removes; a row identical to the previous one
on every hierarchy column adds nothing unless it has details. Rows whose selected
cells are all blank are skipped and do not end a run.

Detail lines and child items under one parent keep the order of the rows that
introduced them. Under `#` headings, a detail line that follows a child section is
printed after that section.

By default only adjacent rows fold, so the outline keeps the sheet's order and a
value that reappears later starts a new run. `--group` merges non-adjacent rows with
the same parent values instead; items keep first-occurrence order. Grouping changes
order relative to the sheet, so it is explicit.

### Blank hierarchy cells

Trailing blank hierarchy cells shorten the row's path: a row `Beta, (blank)` is the
item `Beta` with nothing beneath it. An inner blank (a blank followed by a value)
renders as `--blank-label` (default `(blank)`), because dropping it would place the
deeper value at the wrong level. The label is display only: a blank cell and a cell
whose text equals the label are different values and never fold together.

Sheets laid out for reading often leave a parent blank under its first occurrence.
`--fill-down` treats a blank hierarchy cell as the value above it, but only when
every level to its left matches the row above, so a new parent never inherits the
previous parent's children.

## Markdown output

The default is a nested bullet list with `--indent` spaces per level (default 2,
which CommonMark and GitHub accept; some renderers need 4). `--heading-levels N`
renders the first N hierarchy levels as `#` headings and deeper levels as bullets;
`--title` adds a top `#` heading and moves the others down one level. Markdown has six
heading levels, so headings including the title cannot exceed six. `--label-levels`
prefixes each hierarchy item with its column heading (`Team: Core`).

Cell text is escaped so it reads literally: backslash, backtick, `*`, `_`, brackets
and angle brackets are backslash-escaped, as are a leading `#`, `-` or `+` followed
by a space, a leading `---`, and `1.` or `1)` followed by a space. `--raw` disables
escaping for cells that already contain Markdown.

## Output and exit codes

Without `--output` the outline goes to standard output and a one-line summary to
standard error. With `--output` the file is written as UTF-8 with LF line endings
through a temporary file and an atomic rename. An existing output requires
`--overwrite`; the input workbook is never accepted as the output.

| Exit | Meaning |
| --- | --- |
| 0 | Outline written |
| 2 | Invalid workbook layout, column selection, or option combination |
| 3 | File IO failure, including an unreadable workbook |

## Verification and future work

Tests use generated workbooks to cover folding in sheet order and with `--group`,
headings with title and labels, column reordering, trailing and inner blanks,
`--fill-down` parent boundaries, runs ended by a shorter row, blank cells versus
label text, detail order around children, formatting far from the data, merged cells, value formatting, escaping, cached
formula values, output overwrite protection and validation errors.

The value-bearing table is read into memory. Only cells stored in the file are
visited, so formatting far outside the data does not enlarge the work. Deferred items are listed in the
[backlog](../backlog.md).
